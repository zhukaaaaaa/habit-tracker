# Трекер привычек

Учебный проект на Java 21 и Spring Boot. Уровень 1: REST API с хранением в памяти.

Запуск: `./mvnw spring-boot:run` (Windows: `mvnw.cmd spring-boot:run`).

Swagger: http://localhost:8080/swagger-ui/index.html

Данные первого уровня исчезают при остановке программы. PostgreSQL добавляется на следующем уровне.
